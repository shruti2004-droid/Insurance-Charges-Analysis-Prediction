# Insurance-Charges-Analysis-Prediction
This is my complete end-to-end data analytics and machine learning project where I worked on insurance customer data to analyze medical charges and build a prediction model.  In this project, I tried to cover the full workflow starting from data cleaning and SQL analysis to machine learning, dashboard creation, and a Streamlit prediction app.

# What I worked on
Cleaned and explored the insurance dataset
Performed SQL queries for analysis
Used Python for EDA and visualization
Built a Linear Regression model for insurance charge prediction
Created an interactive Power BI dashboard
Developed a Streamlit app for prediction testing

# Main Insights
Smokers had much higher insurance charges compared to non-smokers
Insurance charges generally increased with age
Higher BMI values were often linked with higher medical costs
Regional differences also affected average charges
